# فیکا چمپیون

لیگ پیش‌بینی دوستانه فصل ۲۶/۲۷ مطابق سند تعریف پروژه ۱.۱.

هیچ نشان باشگاه یا توپ رسمی در محصول نیست. آیکن ستاره و فنجان است.

## اجرا

```bash
node server.mjs
```

بعد در مرورگر: `http://127.0.0.1:8787`

برای استفاده گروهی، همین پوشه را روی میزبان ابری با HTTPS بگذارید. فروشگاه اپ و سرور خانگی جزء محصول نیستند.

اولین حساب ساخته‌شده مدیر می‌شود و کد دعوت می‌سازد. نفرهای بعدی فقط با همان کد وارد گروه می‌شوند.

## قانون امتیاز

- نتیجه دقیق ۵
- تفاضل درست ۳
- فقط برنده ۲
- وگرنه صفر

بونوس‌ها روی پایه اضافه می‌شوند:

- حذفی و پایه بیشتر از صفر: ۲+
- نیمه‌نهایی یا فینال و نتیجه دقیق: ۳+
- مساوی واقعی و مساوی پیش‌بینی‌شده: ۱+
- سومین / ششمین / … درست پیاپی به ترتیب سوت: ۵+

گل وقت اضافه حساب است. ضربه پنالتی گل نیست.
قفل ۱۵ دقیقه قبل از سوت با ساعت سرور است.
امتیاز را سرور حساب می‌کند، نه گوشی.
